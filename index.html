Make.com 자동화 연결
Make.com에서 매일 정해진 시간에 청약 API를 체크하고, 조건에 맞는 공고가 있으면 자동으로 알림을 보냅니다.
  1. make.com 로그인 후 새 시나리오 생성
  2. Schedule 트리거 → 매일 오전 9시 설정
  3. HTTP 모듈 → 청약홈 API 호출
    https://www.applyhome.co.kr/ai/aia/selectAPTLttotPblancListView.do
  4. JSON Parse → 결과에서 조건 필터링
  5. 매칭되는 공고가 있으면 → HTTP POST로 위 Webhook URL 호출
  6. Slack payload 예시:
    {"text":"🏠 새 청약 공고: 마포 래미안 D-7"}
  7. Discord payload 예시:
    {"content":"🏠 새 청약 공고: 마포 래미안 D-7"}
